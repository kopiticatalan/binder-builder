1 · Title Page ▾

Each line is centred by default · start a line with L: to left-align it · wrap text in **double asterisks** to make it bold · press Tab between a party's name and their designation to push the designation to the right margin (e.g. L:ABC Ltd. ⇥ …Petitioner). Blank lines create spacing.

2 · Formatting ▾

Numbering always starts at 1 from the title page and is stamped on every page automatically.

3 · Index Columns ▾

Column NameContent TypeWidth
Auto serial numbers rows 1., 2., 3.… · Case name + citation gives two boxes per document (name prints bold, citation italic) · Free text is any text you type per document (supports **bold**) · Auto page range fills in "x - y" from the actual pagination. Width is relative (e.g. 7 / 59 / 22 / 12).
