Binder Builder for Mac
======================

1. Unzip this file.
2. Drag “Binder Builder” into Applications.
3. Right-click it → Open → Open.

macOS asks once because this is not from the App Store.
After that, open it like any other app.

Needs Python 3, which macOS already has (or install with:
xcode-select --install). No Node. No npm. No “are you online” install.

From court, cause lists and order PDFs work in this Mac app.
The public web page is a static preview and cannot scrape court sites.

Apple Silicon (M1 / M2 / M3 / M4).
